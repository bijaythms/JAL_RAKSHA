🌊 QUICK START: DAM BREACH ANALYSIS

Follow these 4 steps to run a flood simulation and get evacuation maps

1️⃣
SELECT A DAM / INCIDENT
Click the 🌊 SELECT DAM button in the top bar to browse 65+ Indian dams, or create a new incident from the DAM ANALYSIS tab. The selected dam will appear on the map.
2️⃣
DEFINE THE BREACH SCENARIO
Go to ⚡ BREACH SIMULATION in the sidebar. Set the breach size, dam material, and reservoir volume. Then click RUN SIMULATION — takes 10-30 seconds.
3️⃣
VIEW INUNDATION MAP & FLOOD WAVE
After simulation, the 🌊 INUNDATION MODEL tab shows the flood map. Use the ▶ PLAY button on the timeline to watch the flood wave propagate. Hover over areas to see depth and arrival time.
4️⃣
EXPORT EMERGENCY MAPS
Download the complete GIS package using 📦 Download Shapefile (for QGIS/ArcGIS) or 🌍 KML (for Google Earth). Contains inundation zones, affected buildings, population areas, and arrival time contours.
